# 🛠️ Bike Service Management API

A backend API for managing bike service records, customers, and bikes. Built with TypeScript, Express.js, Prisma ORM, and PostgreSQL, this system helps track service progress, overdue cases, and completion logs efficiently.

---

## 🔗 Live Backend

[https://b4-a8-bike-servicing-management.vercel.app](https://b4-a8-bike-servicing-management.vercel.app)

---

## ⚙️ Tech Stack

- Node.js
- Express.js
- TypeScript
- Prisma ORM
- PostgreSQL

---

## 🚀 Setup Guide

1. **Clone the Repository**
   ```bash
   git clone https://github.com/umayeremon/bike-servicing-management-api-B4A8
   cd bike-service-api
   ```

✨ Key Features
✅ Add & manage customers and bikes

🔧 Create, update, and track bike service records

🕒 Mark services as completed (auto or custom timestamp)

⏳ Identify overdue/pending services older than 7 days

📦 RESTful API with TypeScript support
